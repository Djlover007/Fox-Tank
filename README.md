# Fox Tank

Android-App für günstiges Tanken – Design by Mr.Fox.

- **Preise in der Nähe:** Super E5, E10 und Diesel, als Liste oder Karte, sortiert nach Preis oder Entfernung
- **Favoriten:** bis zu 10 Tankstellen mit allen Preisen auf einen Blick
- **Preis-Alarm:** Push-Nachricht, wenn eine Tankstelle unter deinen Wunschpreis fällt
- **Tankbuch:** Tankfüllungen eintragen, Verbrauch (l/100 km) und Kosten pro Monat

Preise: [Tankerkönig](https://www.tankerkoenig.de) (MTS-K), Lizenz CC BY 4.0. Für echte Preise braucht man einen kostenlosen Schlüssel von onboarding.tankerkoenig.de, ohne Schlüssel zeigt die App Beispieldaten.

Die APK baut GitHub Actions bei jedem Push, Download unter *Releases*. Updates gibt es in der App über Einstellungen › App-Update.
